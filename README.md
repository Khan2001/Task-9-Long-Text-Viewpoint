## 赛题

### 一、赛题名称

谈判对手长文本观点挖掘与预测

### 二、赛题背景

边防会谈会晤机制是我国与邻国边防部队交涉边界问题、处理边境事务、开展边防交往合作的重要途径，其中，中印两军举行的边防会谈会晤是近年来我对印军事斗争的重要组成部分，在维护领土主权、争取外交主动、调整斗争策略上起到重要作用。举行会谈之前，从对方相关的新闻报道、外交发言、政策公报及以往会谈记录等内容中获取对手对特定主题或议题的观点、论据和倾向等内容，进而预判其在下次会谈可能持有的态度立场和博弈底线，是掌握谈判主动权、优化我方谈判方案的重要支撑，直接影响谈判策略制定的针对性与前瞻性。

解决上述问题的难点在于长文本的深层语义理解与关联推理。长文本篇幅冗长、表述隐晦且包含外交辞令与修饰内容，针对某一主题议题的观点常常具有碎片化、间接化等特征。如何从多项论述中精确辨识与谈判议题强相关的有限立场句段、如何消解不同来源文本的表述差异与表面矛盾实现对立场的持续性追踪、如何基于历史语义脉络构建预测模型进而推断对手在某主题议题的可能未来观点（论点），是解决问题面临的主要挑战。

### 三、赛题任务

参赛者须以主办方指定版本的开源 Qwen3 32B 大模型为唯一生成基座模型（模型参考链接 [https://www.modelscope.cn/models/Qwen/Qwen3-32B](https://www.modelscope.cn/models/Qwen/Qwen3-32B) ），完成复杂长文本中的议题与观点抽取及未来观点（论点）预测任务。模型需要从给定文本中识别与谈判相关的议题，判断各议题下的立场倾向，定位支撑立场的原文证据，并预测后续可能出现的观点表达和论证方向。不得以其他大语言模型、在线大模型服务或人工服务替代指定基座生成最终提交结果。

第一项任务为议题与观点抽取。模型需要从新闻报道、政策文件、官方发言、联合声明、评论文章等非结构化长文本中识别主议题（核心议题）及相关子议题，并针对每个议题输出议题名称、立场标签和原文证据链。

第二项任务为未来观点（论点）预测。模型需要基于已识别议题、历史立场和原文证据链，预测各议题后续可能出现的观点表达和论证方向，并按照议题顺序输出对应结果。

该任务的技术难点在于议题线索分散、观点表达隐晦、多主体立场交织且有效证据稀疏。模型需要具备长文本理解、议题识别与归纳、立场判断、证据定位和可控生成等综合能力。

## 数据

### 一、数据简介

随着国际交流与多边对话日益频繁，新闻报道、政策文件和官方发言等公开文本快速增长，已成为研判行为体立场与意图的重要信息源。如何从海量非结构化长文本中高效提炼隐含观点、梳理论据并预测立场演化趋势，成为战略分析、商业竞合和公共政策研究的共性需求。传统人工研判效率有限，自动化分析仍面临长文本语义聚焦、跨篇章立场对齐与趋势预测等关键问题。

数据集文本来源于公开渠道，涵盖国际新闻、政策文件、官方发言、联合声明、评论文章和公开谈判记录等内容。构建过程中，首先完成文本清洗和质量筛选；随后分析不同参与方的表态和分歧焦点，识别并归纳相关议题；在此基础上，为各议题标注立场倾向和原文证据，并结合议题脉络生成未来观点（论点）；最后开展格式与质量校验，保证数据结构完整、证据可追溯以及议题与预测结果对应一致。

初赛阶段数据集采用开源数据，涵盖国际新闻报道、官方发言人答记者问、政策白皮书节选、通讯社评论文章、联合声明及会议公报等非结构化长文本，每条样本主要围绕一个相对完整的主题或讨论场景展开，用于支撑模型从非结构化长文本中自主识别和归纳议题，并围绕所识别议题完成立场判断、证据链定位和未来观点预测能力的基础验证。数据集划分为训练集、验证集和测试集。其中，训练集2400条、验证集300条、测试集300条。

复赛阶段数据集采用会谈对话类型的长文本数据，包括各类国内外事件的官方表态与谈判记录。围绕同一会谈场景组织三方的公开表态，体现三方立场、论据交织和观点演化等复杂特征。数据同样来源于公开资料，经领域专家筛选与标注，模拟真实会谈会晤的语义复杂性与立场演化特征，重点考察模型在复杂谈判语境下识别共同议题、区分不同参与方立场、关联原文依据和推演后续观点的进阶能力。复赛阶段数据集数据分布与难度较初赛提升，用于模型进阶能力自动化比测，包括训练集1600条、验证集200条、测试集200条。

### 二、数据说明

数据集文件格式说明如下：

| **项目** | **说明** |
| --- | --- |
| 文件名称 | train.jsonl / val.jsonl / test.jsonl |
| 文件编码 | UTF-8 |
| 数据格式 | JSON Lines，每行为一个完整样本的JSON对象 |

数据字段详细说明如下：

| **字段名称** | **字段类型** | **字段说明** | **提供范围** |
| --- | --- | --- | --- |
| sample\_id | string | 样本唯一标识符，格式：SAMPLE\_XXXX | 全量数据集 |
| docs | array\[dict\] | 时间序列长文本列表，按 publish\_date升序排列 | 全量数据集 |
| docs\[\].doc\_id | string | 文档唯一标识符 | 全量数据集 |
| docs\[\].doc\_type | string | 文档类型（中文）：公开谈判记录、国际会议发言、外交会谈文本、多方磋商记录、新闻发布会实录等 | 全量数据集 |
| docs\[\].publish\_date | string | 文档发布日期，格式：YYYY-MM-DD | 全量数据集 |
| docs\[\].full\_text | string | 文档组成的长文本内容 | 全量数据集 |
| issue\_list | array\[dict\] | 议题以及模型从长文本中抽取的立场、论据链 | 全量数据集 |
| issue\_list\[\].issue\_name | string | 议题名称 | 全量数据集 |
| issue\_list\[\].stance | string | 立场倾向：support/oppose/neutral | 仅训练集、验证集 |
| issue\_list\[\].argument\_chain | array\[string\] | 支撑论点文本片段序列 | 仅训练集、验证集 |
| future\_argument | array\[string\] | 未来观点（论点）论据段落（预测目标） | 仅训练集、验证集 |

每条样本包含sample\_id、docs、issue\_list、future\_argument等字段。文本内容涵盖相关背景、参与主体、各方表态和分歧焦点等信息。数据构建过程中，围绕文本中的谈判焦点识别并归纳主议题及其相关子议题，形成层次化议题结构。

**初赛数据集** ：初赛的full\_text主要由围绕同一主题的单篇长文本构成。issue\_list\[0\]表示主议题，后续元素表示子议题。每个议题均标注议题名称issue\_name、立场标签stance和来自原文的证据argument\_chain。未来观点（论点）预测future\_argument按照主议题及各子议题在issue\_list中的顺序组织。

**复赛数据集** ：复赛的full\_text长文本由同一会谈场景下三方的公开发言共同组成。对于主议题，三个参与方均须形成各自独立的主议题三元组。因此，同一主议题的议题名称issue\_name应在 issue\_list中出现三次，并分别标注各方的立场stance和原文证据链 argument\_chain。对于子议题，仅标注在原文中实际发表了相关观点且能够找到有效证据的参与方。同一子议题可能只有一方或两方涉及，不要求三个参与方均生成议题三元组；但对于已经表达相关观点的参与方观点，尽可能完整抽取。未来观点（论点）预测future\_argument按照主议题及各子议题在issue\_list中的顺序组织。

**注** ：复赛的主议题需要为每个参与方分别形成议题三元组，即使立场相同也不能合并；子议题则依据长文本中的实际表态进行抽取，并尽可能完整抽取涉及该议题的各参与方观点；涉及几方，该子议题应形成相应数量的议题三元组。

## 评测标准

本赛题评测总体沿用观点抽取和未来观点（论点）预测两项任务指标，分别考察模型对复杂长文本中议题、立场、证据链的抽取能力，以及基于既有议题脉络和观点依据进行后续论点预测的能力。复赛阶段面向公开三方谈判文本，评测时以测试集标注结果为基准，按sample\_id对模型输出文件和参考答案文件进行对齐，并在同一样本内进行比较。综合得分由观点抽取指标和未来观点（论点）预测指标等权融合得到。

### （1）观点抽取指标

细粒度语义F1：该指标评估模型从长文本中抽取的核心观点要素与参考标注的一致性。观点要素定义为议题、立场倾向、关键论据片段三元组。是否正确抽取判定按三项分别进行：立场倾向须严格一致，模型预测与标注参考完全相同方可参与后续匹配；议题名称与论据链内容分别使用BAAI/bge-small-zh-v1.5模型计算向量余弦相似度，并按议题占0.4、论据占0.6的预设权重加权，得到三元组级语义等价分；该分值超过预设阈值0.7则视为正确抽取。由于实际模型生成的议题顺序可能与数据集标注顺序不一致，评测时采用最大二部图匹配方法：模型预测的每个观点三元组会与数据集标注中的所有观点三元组计算语义等价分，并在满足阈值条件的前提下进行一对一最优匹配，以避免因顺序差异影响评分。设正确抽取三元组要素数量为NC，模型预测三元组要素总数为Np，数据集实际参考三元组要素总数为Ng，则精确率P=NCNp，召回率R=NCNg，观点抽取得分：

$$
F 1_{ext} = \frac{2 P R}{P + R}
$$

该指标重点衡量模型对复赛多方谈判长文本中议题、立场表达和原文证据的抽取能力，并间接反映其对多方观点关系和文本语义脉络的理解水平。

语义修正系数α：为缓解字面匹配对同义改写、句式变换等语义等价表达的误判，对每个成功匹配的三元组额外计算BERTScore-F1。抽取语义修正和未来观点语义相似度统一使用bert-base-chinese模型，取所有匹配三元组的均值作为语义修正系数α(α∈\[0,1\])。

评测模型配置固定如下：BAAI/bge-small-zh-v1.5用于议题和证据链的三元组语义匹配；bert-base-chinese用于观点抽取语义修正和未来观点语义相似度计算；正式评测不调用大模型裁判服务。

语义修正后的观点抽取阶段得分为：

$$
S_{ext} = F 1_{ext} \times \left(0.7 + 0.3 \alpha\right)
$$

该设计以基础三元组匹配F1为核心，并通过语义修正系数缓解同义改写和句式变化带来的误判。由于立场已经作为观点三元组的必要匹配条件参与计算，因此不再设置独立的立场修正项。各分项均归一化至\[0,1\]，观点抽取阶段得分也位于\[0,1\]区间。

### （2）未来观点（论点）预测指标

ROUGE-L F1：该指标评测模型依据已抽取的议题、立场和论据链预测后续观点时，与参考未来观点（论点）之间的一致性。future\_argument是按issue\_list排列的论点列表，未来观点（论点）预测的第k项对应观点抽取的第k个议题。由于模型生成的议题顺序未必与标注一致，若按列表位置直接配对，会因顺序差异误判正确内容。因此，未来观点（论点）预测评测复用观点抽取阶段的议题匹配结果：对于每一对成功匹配的议题，取标注参考样本中第i条future\_argument为Y、模型预测样本第j条为X，计算ROUGE-L F1：

$$
R_{l c s} = \frac{\left|LCS \left(X , Y\right)\right|}{\left|Y\right|} , P_{l c s} = \frac{\left|LCS \left(X , Y\right)\right|}{\left|X\right|}
$$
 
$$
F 1_{l c s} = 2 \cdot \frac{P_{l c s} \cdot R_{l c s}}{P_{l c s} + R_{l c s}}
$$

样本的未来观点（论点）预测得分由所有议题匹配结果共同决定。设M为成功匹配的议题对集合，Ng为参考议题数量，Np为模型预测议题数量，N=max(Ng,Np)。

$$
F 1_{pred} = \frac{\underset{\left(i , j\right) \in M}{\sum} F 1_{lcs} \left(i , j\right)}{N}
$$

成功匹配的议题对按实际ROUGE-L F1计分；未召回的参考议题和多余的预测议题均按0分计入样本级平均。采用参考议题数与预测议题数的较大值作为分母，同时惩罚议题漏召回和过度预测，并消除议题输出顺序对评分的影响。

未来观点语义相似度：对每一对成功匹配的议题，使用bert-base-chinese模型计算模型预测未来观点与参考未来观点之间的BERTScore-F1。未召回的参考议题和多余的预测议题均按0分计入样本级平均，计算如下：

样本级未来观点语义相似度为：

$$
S_{semantic} = \frac{\underset{\left(i , j\right) \in M}{\sum} BERTScoreF 1 \left(X_{j} , Y_{j}\right)}{N}
$$

未来观点（论点）预测阶段得分为：

$$
S_{pred} = 0.6 \times F 1_{pred} + 0.4 \times S_{semantic}
$$

F1pred用于衡量预测观点与参考观点在关键词、表达结构和序列顺序上的一致性，Ssemantic用于衡量措辞不同情况下的整体语义一致性，二者共同构成未来观点预测得分。

### （3）综合得分

综合得分按照观点抽取指标占80%、未来观点预测指标占20%的权重加权计算：

$$
Score = 0.8 \times S_{ext} + 0.2 \times S_{pred}
$$

两阶段指标分别检验模型在多方谈判文本中的观点抽取能力与后续观点推演能力，总得分高位者具备更强的谈判对手意图研判综合优势。

**答：** 可以在官方训练数据及合规的外部无标注数据上使用自动伪标签，但须披露生成和筛选流程。不得对测试集进行人工标注，也不得依据非公开评测反馈反推并回填测试答案。

**Q3** **是否必须使用** **Qwen3 32B** ？

**答：** 是。所有参赛方案必须以开源Qwen3 32B为基座。未使用指定基座，或无法在复现材料中证明实际使用情况的，成绩无效。

**Q4** **是否允许** **LoRA** 、 **QLoRA** 、 **全量微调或量化？**

**答：** 允许。参赛者可根据资源条件选择微调与量化方式，但需提交相应权重、配置、量化方案和依赖版本，并保证复现结果稳定。

**Q5** **是否允许使用辅助模型或多模型融合？**

**答：** 允许使用开源嵌入、重排、分词、聚类等辅助模块，也允许融合由同一 Qwen3 32B 基座产生的检查点或推理结果；不得让其他闭源或不同大语言基座参与最终答案生成。

**Q6** **可以调用在线大模型或第三方** **API** **吗？**

**答：** 不可以。正式结果应由可离线复现的本地方案生成，不得依赖商业API、远程人工服务或不可审计的在线推理接口。

**Q7 argument\_chain** **可以概括或改写原文吗？**

**答：** 不建议。该字段用于证据链抽取，应尽量保留原文关键句段，确保能够在输入文本中定位和核验。概括、改写或加入模型生成内容可能降低匹配得分。

**Q8** **议题顺序与参考答案不同会扣分吗？**

**答：** 不会因顺序本身直接扣分。评测采用一对一最优匹配，但每条future\_argument必须与本队输出的对应议题保持相同顺序。

**Q9 future\_argument** **数量可以少于** **issue\_list** **吗？**

**答：** 不可以。两者必须逐项对应、长度一致；未匹配议题或缺失的预测内容不能获得相应分数。

**Q10 result.jsonl** **外层是否需要方括号？**

**答：** 不需要。建议统一采用标准JSON Lines：每行一个JSON对象，不使用最外层数组。文件名固定为 result.jsonl，编码为UTF-8无BOM。

**Q11** **可以只提交适配器权重，不提交完整基座吗？**

**答：** 可在赛方已具备同版本 Qwen3 32B 基座的前提下提交适配器权重，但必须准确注明基座来源、版本或提交哈希，并提供可自动加载和合并的脚本。赛方要求完整权重时，应按通知补充。

**Q12** **复现结果与线上结果略有差异怎么办？**

**答：** 应固定随机种子、解码参数和依赖版本，并说明可能产生非确定性的算子或并行策略。差异须处于赛方认可范围；差距较大且无法合理解释的，方案视为无效。

**Q13** **初复赛数据集差异是什么？**

**答：** 初赛数据集来源采用开源数据，涵盖国际新闻报道、官方发言人答记者问、政策白皮书节选、通讯社评论文章、联合声明及会议公报等非结构化长文本，复赛数据集来源采用会谈对话类型的长文本数据，包括各类国内外事件的官方表态与谈判记录。数据同样来源于公开资料，经领域专家筛选与标注，模拟真实会谈会晤的语义复杂性与立场演化特征。初赛以单篇文本为主要分析对象，围绕文本的整体观点组织一个主议题及若干子议题，每个议题对应一个议题三元组，重点考察基础的议题抽取、立场判断、证据定位和未来观点预测能力。复赛则采用“主议题全覆盖、子议题按实际观点覆盖”的标注原则：主议题需要为每个参与方分别形成议题三元组，即使立场相同也不能合并；同一个子议题仅标注实际发表相关观点且具有原文证据的参与方，多方涉及时分别形成议题三元组。因此，复赛进一步考察多篇长文本和多参与方场景下的主体区分、议题对齐与立场推演能力。
